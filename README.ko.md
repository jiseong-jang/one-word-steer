# one-word-steer

[English](README.md) | **한국어**

**"비슷한데 뭔가 아닌" AI 답변을 단어 하나로 고치세요.**

모든 열린 질문의 답변을 한 단어로 조정할 수 있게 해 주는 [Claude 에이전트 스킬](https://docs.claude.com/en/docs/agents-and-tools/agent-skills/overview)입니다.

---

## 문제

AI에게 "이 문서 요약해줘"라고 했습니다. 답이 나쁘진 않은데 너무 길거나, 너무 어렵거나, 원하던 내용이 아닙니다. 뭐가 문제인지 말로 설명하기는 어렵고, 프롬프트를 다시 쓰기는 귀찮습니다.

## 동작 방식

Claude가 답변 위에 어떤 기준으로 만들었는지 짧은 꼬리표로 보여주고, 아래에 한 단어 선택지를 2~3개 붙입니다.

```
사용자: (report.pdf 첨부) 이 문서 요약해줘

Claude:
📌 전체 흐름 · 6줄 · 실무자용

- 3분기 매출 412억 원, 전 분기 대비 8% 증가
- ...

다르게 원하면 한 단어로 → 한줄 · 숫자만 · 할일
```

단어 하나만 입력하면 그 기준 하나만 바뀌고 나머지는 그대로 유지됩니다.

```
사용자: 할일

Claude:
📌 할 일 중심 · 6줄 · 실무자용      ← 초점만 바뀜

- 가격: 단건 판매 가격 구조 재설계
- ...

다르게 원하면 한 단어로 → 짧게 · 표 · 보고체
```

### 핵심 원칙

- **설명하지 않고 보여줍니다.** 기준은 문장이 아니라 꼬리표("5줄", "입문자용")로 표시합니다.
- **단어 하나는 기준 하나만 바꿉니다.** 기준은 분량 · 난이도 · 초점 · 형식 · 말투 다섯 가지입니다. "쉽게"라고 해도 분량은 바뀌지 않습니다.
- **선택지는 답변마다 새로 고릅니다.** 고정 메뉴가 아니라, 이번 답변이 빗나갔을 가능성이 가장 큰 방향을 제시합니다.
- **자유롭게 입력해도 됩니다.** "보고용", "슬랙에 올릴 거"처럼 입력하면 Claude가 이를 기준으로 해석합니다. 새 꼬리표에 해석 결과가 드러나므로, 틀렸다면 단어 하나로 바로 고칠 수 있습니다.
- **되묻지 않습니다.** 정말 해석이 불가능한 단어가 아니면 질문 없이 바로 다시 만듭니다.
- **선택을 기억합니다.** 한 번 고른 기준은 대화가 끝날 때까지 유지됩니다.
- **방해하지 않습니다.** 짧은 사실 답변, 코드, 가벼운 대화에는 붙지 않습니다.
- **사용자의 언어를 따릅니다.** 꼬리표와 선택지는 사용자가 쓰는 언어로 표시됩니다.

## 설치

### Claude Code

```bash
# 개인용 (모든 프로젝트)
git clone https://github.com/jiseong-jang/one-word-steer.git ~/.claude/skills/one-word-steer

# 프로젝트용
git clone https://github.com/jiseong-jang/one-word-steer.git .claude/skills/one-word-steer
```

### Claude.ai (웹 / 데스크톱)

1. 이 저장소를 ZIP으로 내려받습니다 (`SKILL.md`가 최상위에 있는 `one-word-steer` 폴더).
2. 설정 → Capabilities → Skills → **Upload skill**에서 업로드합니다.

### 그 외 에이전트 스킬 호환 도구

사용하는 도구의 스킬 폴더(예: `.agents/skills/`)에 이 폴더를 복사합니다.

## 구성

```
one-word-steer/
├── SKILL.md              # 발동 조건, 출력 형식, 조정 규칙
├── references/
│   └── axes.md           # 5가지 기준, 선택지 단어 사전, 자유 단어 해석표
└── examples/
    ├── summary.md        # 보고서 요약
    ├── explain.md        # 개념 설명
    └── free-word.md      # 선택지에 없는 단어를 입력한 경우
```

## 커스터마이즈

`references/axes.md`를 수정해 단어나 기준을 추가할 수 있습니다. 예를 들어 팀에 맞는 "대상 독자" 기준(디자이너용 / 개발자용 / 경영진용)을 넣거나, 계약서용으로 조항 · 기한 · 위약금 같은 초점을 추가할 수 있습니다.
